# 🐍 Snake Game (HTML / CSS / JavaScript)

간단하고 클래식한 **스네이크 게임(Snake Game)**입니다.  
HTML 한 파일 안에 **CSS와 JavaScript가 모두 포함된 구조**로 제작되어, 브라우저에서 바로 실행할 수 있습니다.

---

## 🎮 게임 특징

- 방향키(↑ ↓ ← →)로 뱀을 조작  
- 먹이를 먹을 때마다 길이가 증가  
- 벽 또는 자신의 몸과 충돌하면 게임 오버  
- 점수 시스템 포함  
- “다시 시작” 버튼으로 즉시 재시작 가능  
- Canvas 기반 렌더링

---

## 📂 파일 구성

이 프로젝트는 **단일 HTML 파일**로 구성됩니다.
